# 学生登录与提交作业

- 适用角色：学生
- 前置条件：学生端可访问；管理员/老师已发放账号信息
- 最后验证日期：2026-10-12

## 登录流程
1. 进入学生端：`http://localhost:3001`。
2. 在侧栏「学习概览」中输入姓名、班级（重名时必填）和密码。
3. 点击「确认认证」完成登录。
4. 忘记密码时联系老师在老师端重置默认密码。

## 今日任务、陪练与提交
登录后首页是「今日任务」。聊天和聊天附件只是陪练，**对话不会记为提交**。行内提示是「聊天是陪练，不是提交」。正式提交走首页或聊天里按 kind 显示的提交按钮，调用 `POST /student/submit`。

列表按钮随作业类型变化（不是固定「提交作业」四个字）：

| `assignment_kind` | 提交按钮 |
| --- | --- |
| 做题 `problem_set` | 提交作业 |
| 情景 / 科学史 | 提交书面/照片 |
| 实践 | 提交实践照片 |

1. 在「今日任务」首页查看当天各科作业。空态文案是「老师尚未布置」，没有生成按钮，也没有补练卡。
2. 点击「进入任务」打开聊天陪练；可用输入框旁的「+」添加附件，这些附件不会自动记为作业提交。对话不是提交，也不是官方分。绑定作业后 extra_system 注入老师材料派生的 **【考查清单】**（stems / brief / 讨论目标 / 额外限制），一次只问一项，不另编题干或情景；空 discussion_goals 用 bounded brief 摘录，不发明题干。聊天条按钮名随 **当前选中作业** 的 kind，与上表相同。
3. 准备交卷时点击对应提交按钮（做题「提交作业」／情景与科学史「提交书面/照片」／实践「提交实践照片」），打开提交面板并选择文件。可选「把当前聊天附件作为本次提交」，预览后必须再点一次「确认提交」才会 POST。
4. 若返回 `submitted=false`（有效评分不足），界面会明确提示「未记为提交」，首页「已提交」只认 progress API，不看聊天完成。自动评分失败（OCR 缺失、脚本超时）不是提交失败：文件已保存，成绩记为 ungraded，HTTP 仍 200；老师在进度面板覆盖分数。情景/实践没有题目行时，提交照片会记为已交（`received_without_items`），官方分仍空，直到老师覆盖（非做题可 enqueue 量规建议，LLM 不挡 200，也不直接写官方分）。
5. 「作业记录」打开作业历史（材料 / 官方分 / 未交补交）。画像卡只放这一页。「历史任务」仍是会话侧栏，两者不是同一个入口。画像卡含：近期薄弱知识点、下一步、**最近作业**（最多 **5** 条 history：`kind · 已提交|未提交 · 官方分|已交未评分|—`）、**最近补练**（`practice_history` **从尾向前** 第一条带 `practice_id` 的；homework `brief_fallback` 不当补练；没有则「暂无」）。禁止把 `practice_history[0]`（最旧保留项）当成最近。不要读 `weak_kp`。

## 补练（仅做题，且必须先交作业）
补练 **不是** 今日任务卡，也不是聊天里的「生成题目」。

- 只对做题作业（`assignment_kind=problem_set`）且老师允许补练（`allow_practice`）。
- **补练按钮只在该份作业已交之后出现**（作业记录页或做题提交成功区）。未交时 SPA 不渲染入口，因此没有「请先提交作业」toast。接口若仍被直接调用，服务端 409 `homework_not_submitted`（防御码；学生端 `ERROR_CODE_MESSAGES` 不映射这条）。
- 情景 / 科学史 / 实践 **没有** 补练按钮；打接口会 409 `practice_not_applicable`（同样不展示入口）。
- 入口出现后点「补练」→ `POST /student/assignment/{assignment_id}/practice`。服务器从自建题库选题，不让模型编题。
- 空库 → 「题库不足」（409 `question_bank_insufficient`）。这是预期：`questions.csv` 只有表头时不要编题。老师 how-to 有可选 env 检查（`data_rows==0`）。
- 交补练走 `POST /student/assignment/{assignment_id}/practice/{practice_id}/submit`，不计入作业官方分，也不把今日列表标成新作业。

## 验证结果
- 能成功登录并进入「今日任务」首页。
- 能进入聊天并发送文字或附件，且知道对话不会记为提交。
- 能从提交面板提交文件，并在失败时看到未记为提交。做题看到「提交作业」；实践看到「提交实践照片」。
- 自动评分失败时提交仍 200 落盘，成绩为 ungraded，不是整次提交失败。
- 能从「作业记录」查看已提交分数或补交；画像卡能看到最近 5 条作业与最近补练（有 `practice_id` 才标补练）；做题已交后才看到「补练」；非做题看不到补练。

## 常见问题
- 同名学生无法定位：补充正确班级。
- 密码错误或忘记：联系老师重置密码并重新登录。
- 登录后访问受限：检查是否使用了他人 `student_id` 导致越权拦截。
- 找不到补练：先确认这是做题作业、已经提交，且老师没有关掉「允许补练」。
