# 老师日常教学闭环

- 适用角色：老师
- 前置条件：老师端可访问，API 服务健康；已登录老师账号
- 最后验证日期：2026-09-02

## 目标
完成一次作业主线：**上传材料 → 审核草稿并确认创建 → 查看完成进度**。这不是考试分析流程，也不再走 2026-02-15 的「上传试卷生成讲评」路径。

学生侧配套说明见 `docs/how-to/student-login-and-submit.md`（今日任务 + 显式「提交作业」，对话不算提交）。

## 步骤
1. 打开老师端 `http://localhost:3002` 并登录。
2. 打开工作台「工作流」。主线是「上传作业文件」，不是考试上传。
3. **上传**：填写作业编号、学科、范围（公共 / 班级 / 私人），选择作业文件（必填）和答案（可选），提交解析。班级作业的班级应来自 `GET /teacher/roster`，不要手填未任教班级。
4. 等待后台解析完成（上传区显示进度）。解析生成题目列表与 8 点作业要求。
5. **确认**：在「解析结果（审核/修改）」里核对题目与要求。可先「保存草稿」。8 点要求补全后点「创建作业」，调用 `POST /assignment/upload/confirm`。缺项时按钮不可用。
6. **进度**：创建成功后看「作业完成情况」（`GET /teacher/assignment/progress`）。跟进应交 / 完成 / 已评分 / 逾期。学生正式提交走学生端「提交作业」，不是聊天。
7. 需要下线时，在进度面板归档（`POST /assignment/{id}/archive`）；取消归档走 unarchive。

## 验证结果
- 上传后能看到解析进度，完成后出现可编辑草稿。
- 「创建作业」成功后，`data/assignments/<assignment_id>/` 有作业，进度面板能刷出人数。
- 学生端「今日任务」能看到该作业（已发布且学生在名册内）；空态是「老师尚未布置」，没有生成按钮。
- 学生提交后，进度里的已评分/完成会更新；`submitted=false` 不会把首页标成已交。

## 常见失败
- 上传失败：检查文件格式、大小与网络（见 `docs/reference/upload-resource-guardrails.md`）。
- 无法创建：8 点要求未补全，或解析尚未 `done`。
- 进度空白：作业未确认创建，或当前账号不是该作业 `teacher_id`。
- 学生看不到作业：未发布、不在名册、或作业仍是 `orphan_draft`。孤儿作业需管理员 `POST /auth/admin/assignments/{id}/claim` 认领到合法老师和学科（禁止默认 id `teacher`）。
- 学科文案不对：pack 从 `packs/subjects/<id>/` 读取；未知学科回退 `generic`，不会回退物理。

## 布置物理作业
物理是学科，不是单独产品。名册里该老师要有 `subject_id=physics` 的任教记录，上传时学科选「物理」，其余步骤与上面相同。

任教物理的老师登录后，能力列表会**额外**出现 pack 附属能力（课堂采集 / 核心例题 / 学生重点）。未任教物理的老师看不到它们。布置课后作业不依赖这些附属能力。
