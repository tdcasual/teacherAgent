# 学生登录与提交作业

- 适用角色：学生
- 前置条件：学生端可访问；管理员/老师已发放账号信息
- 最后验证日期：2026-08-26

## 登录流程
1. 进入学生端：`http://localhost:3001`。
2. 在侧栏「学习概览」中输入姓名、班级（重名时必填）和密码。
3. 点击「确认认证」完成登录。
4. 忘记密码时联系老师在老师端重置默认密码。

## 今日任务、陪练与提交
登录后首页是「今日任务」。聊天和聊天附件只是陪练，**对话不会记为提交**。正式提交走首页或聊天里的「提交作业」，调用 `POST /student/submit`。

1. 在「今日任务」首页查看当天各科作业。空态文案是「老师尚未布置」，没有生成按钮。
2. 点击「进入任务」打开聊天陪练；可用输入框旁的「+」添加附件，这些附件不会自动记为作业提交。
3. 准备交卷时点击「提交作业」，打开提交面板并选择文件。可选「把当前聊天附件作为本次提交」，预览后必须再点一次「确认提交」才会 POST。
4. 若返回 `submitted=false`（有效评分不足），界面会明确提示「未记为提交」，首页「已提交」只认 progress API，不看聊天完成。
5. 「作业记录」打开作业历史（材料 / 官方分 / 未交补交）。「历史任务」仍是会话侧栏，两者不是同一个入口。

## 验证结果
- 能成功登录并进入「今日任务」首页。
- 能进入聊天并发送文字或附件，且知道对话不会记为提交。
- 能从「提交作业」面板提交文件，并在失败时看到未记为提交。
- 能从「作业记录」查看已提交分数或补交。

## 常见问题
- 同名学生无法定位：补充正确班级。
- 密码错误或忘记：联系老师重置密码并重新登录。
- 登录后访问受限：检查是否使用了他人 `student_id` 导致越权拦截。
