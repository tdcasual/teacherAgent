# 学生登录与提交作业

- 适用角色：学生
- 前置条件：学生端可访问；管理员/老师已发放账号信息
- 最后验证日期：2026-08-26

## 登录流程
1. 进入学生端：`http://localhost:3001`。
2. 在侧栏「学习概览」中输入姓名、班级（重名时必填）和密码。
3. 点击「确认认证」完成登录。
4. 忘记密码时联系老师在老师端重置默认密码。

## 今日任务与聊天
登录后首页是「今日任务」。作业材料通过聊天附件发送，而不是独立提交页。`/student/submit` 只是 API，不是界面入口。

1. 在「今日任务」首页查看当天任务状态（待生成、进入任务、继续任务等）。
2. 点击主按钮进入聊天陪练。
3. 在聊天输入框提问；需要交材料时，用输入框旁的「+」添加附件后再发送。
4. 对话与附件会出现在会话历史中；完成后可从首页查看提交状态。

## 验证结果
- 能成功登录并进入「今日任务」首页。
- 能进入聊天并发送文字或附件。
- 能在会话历史中看到本次记录。

## 常见问题
- 同名学生无法定位：补充正确班级。
- 密码错误或忘记：联系老师重置密码并重新登录。
- 登录后访问受限：检查是否使用了他人 `student_id` 导致越权拦截。
